# 타겟 광고 슬롯 소재 (GIF)

이 폴더에 아래 파일명으로 GIF를 넣으면 앱이 자동으로 표시합니다.
파일이 없으면 규격 안내 플레이스홀더가 대신 보입니다.
(파일 추가 후 `flutter pub get` → 재빌드)

| 파일명 | 위치 | 비율 | 권장 해상도 | 용량/길이 |
|---|---|---|---|---|
| `ad_home.gif` | 홈 대시보드 인라인 배너 | 16:6 (가로형) | 1080 × 405 px | ≤ 3MB · 6~15초 루프 |
| `ad_rewards.gif` | 혜택(포인트) 탭 상단 히어로 | 16:9 | 1080 × 608 px | ≤ 4MB · 6~15초 루프 |
| `ad_products.gif` | 내 제품 탭 하단 배너 | 16:6 (가로형) | 1080 × 405 px | ≤ 3MB · 6~15초 루프 |

## 제작 가이드
- **세이프 영역**: 텍스트/로고는 가장자리에서 8% 안쪽에 배치(모서리 라운딩 22px로 잘림 방지).
- **비율 준수**: 위 비율과 다르면 `BoxFit.cover`로 잘립니다. 비율만 맞으면 해상도는 권장값보다 커도 됩니다.
- **프레임레이트**: 12~15fps 권장(용량 절감). 첫 프레임에 핵심 메시지가 보이게(정지 시에도 의미 전달).
- **가독성**: 우측 상단에 "AD" 라벨이 오버레이되므로 그 자리에 중요한 정보 금지.
- **타겟팅**: 향후 소비자 프로필(설문 응답: 연령대/지역/선호 맛)에 따라 슬롯별로 다른 소재를 서빙할 수 있도록 파일명 규칙을 확장합니다(예: `ad_home__manila.gif`).
