# 타겟 광고 슬롯 소재 (GIF)

이 폴더에 아래 두 파일을 넣으면 앱의 모든 광고 슬롯이 **두 소재를 랜덤으로 회전**하며
표시합니다(슬롯마다 시작 소재가 랜덤이라, 화면의 두 슬롯이 동시에 서로 다른 광고를 돌립니다).
파일이 없으면 규격 안내 플레이스홀더가 대신 보입니다.
(파일 추가 후 `flutter pub get` → 재빌드)

| 파일명 | 내용 | 비율 | 권장 해상도 | 길이 |
|---|---|---|---|---|
| `ad_ecig.gif` | 전자담배(정품 인증) 광고 | 16:9 | 1080 × 608 px | 6~10초 루프 |
| `ad_alcohol.gif` | 주류 광고 | 16:9 | 1080 × 608 px | 6~10초 루프 |

- 슬롯은 3곳(홈·혜택·제품 탭), 모두 16:9로 통일 → **GIF는 두 개만** 만들면 됩니다.
- 슬롯당 6초마다 크로스페이드로 다음 소재로 전환합니다(코드에서 조정 가능).

## 제작·용량 가이드
- **세이프 영역**: 텍스트/로고는 가장자리 8% 안쪽(모서리 22px 라운딩). 우측 상단은 "AD" 라벨이
  덮으니 그 자리에 중요한 정보 금지.
- **GIF 용량**: GIF는 무겁습니다. 960×540·12~15fps·6초 기준 3~6MB를 목표로 하세요.
  원본(mp4)에서 아래처럼 팔레트 방식으로 변환하면 화질/용량이 좋습니다:
  ```bash
  ffmpeg -i ad_ecig.mp4 -vf "fps=14,scale=960:540:flags=lanczos,palettegen" palette.png
  ffmpeg -i ad_ecig.mp4 -i palette.png -filter_complex "fps=14,scale=960:540:flags=lanczos[x];[x][1:v]paletteuse" ad_ecig.gif
  ```
- **연령 규제**: 전자담배·주류는 성인 대상입니다. 앱은 연령인증(AVP)을 거치므로 광고도
  연령인증 완료 사용자에게만 노출하는 것을 전제로 합니다. 화면 하단에 "성인 대상 · 책임 있는
  사용" 문구를 권장합니다.

## 타겟팅 확장(선택)
향후 소비자 프로필(설문 응답: 연령대/지역/선호)에 따라 슬롯별로 다른 소재를 서빙하려면
파일명 규칙을 확장하면 됩니다(예: `ad_ecig__manila.gif`). 코드의 `AdSlot(assets: [...])`에
후보 목록만 넘기면 랜덤 회전됩니다.
