무인 자판기 구매 → 앱 자동 소유권 이전

하이라이트
화면 /kiosk (자판기)폰 ramon@demo.ph

"소비자가 자판기에서 직접 삽니다. 원장으로 정품·연령을 확인하고 배출하면 재고가 실시간으로 하나 줄어듭니다. 그리고 폰으로 QR 한 번이면 소유권이 바로 넘어옵니다."

  1. 자판기: 구매 시작 → 제품 선택 → 정품·판매 가능 확인 → 성인 인증 → 배출 완료 (재고 −1)
  2. 완료 화면의 등록 QR을 폰 앱으로 스캔
  3. 앱: "소유권 이전 · +300P" 즉시 표시 → 제품 탭에 신규 기기 등장
강조매장 직원 승인 없이 스캔 한 번으로 소유권 이전·정품 등록·300P 적립이 끝난다. 종이·수기 제로.

동의 기반 데이터 · 포인트 상부상조

화면 앱 · 혜택 탭계정 ramon@demo.ph

매장 결제 — 쿠폰 QR 스캔·차감

하이라이트
화면 /partner · 매장 결제계정 staff@mm014.test

차별화
화면 /kiosk · /console · /field계정 officer@pnp.test · admin

"통관을 거치지 않은 제품은 자판기·매장에서 판매가 막히고, 관제 콘솔로 밀수 의심 알림이 올라갑니다. 원장은 해시체인이라 당사도 조작할 수 없습니다. 경찰 현장 단말은 스캔 한 번으로 압수 근거와 조서를 만듭니다."
