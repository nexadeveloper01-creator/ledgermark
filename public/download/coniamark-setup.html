먼저 · 안드로이드 기기 준비

APK를 스토어가 아닌 링크로 설치하므로, 기기마다 한 번씩 거쳐야 하는 단계입니다.

  1. 기기에서 Chrome으로 아래 QR을 스캔하거나 주소를 엽니다.
  2. 다운로드 시 파일이 위험할 수 있다는 경고가 뜨면 계속.
  3. 설치 시 알 수 없는 앱 설치가 차단되면 설정 → Chrome에 이 출처 허용 → 뒤로 → 설치.
  4. 기기가 Wi-Fi에 연결되어 있는지 확인합니다. 세 앱 모두 온라인 서버와 통신합니다.

기기를 다 깔았으면 아래를 한 번씩 눌러보고 넘어가세요.

  4. 04노트북 콘솔에서 관세청·운영자 계정이 서로 다른 화면을 보여주는지
